# 🛡️ MailGuard – Email Spoof Detection & Smart Inbox Cleaning

**A Smart Email Security Prototype for Spoof Detection, Email Analysis and Inbox Management.**

MailGuard is a cybersecurity project designed to identify suspicious and spoofed emails, classify incoming messages, quarantine potentially malicious emails, and help users manage inbox storage through an interactive dashboard.

> **Note:** This version currently operates in simulation mode. It does not have a real Gmail account connected.

## 🚀 Features

- **Email Spoof Detection:** Identifies potentially spoofed and suspicious email messages.
- **Email Classification:** Categorizes emails as genuine or spoofed.
- **Email Quarantine:** Isolates suspicious emails from the inbox.
- **Smart Inbox Management:** Provides email cleaning and storage management features.
- **Importance Detection:** Categorizes messages based on their importance.
- **Storage Monitoring:** Displays storage usage and freed storage.
- **Manual Email Analysis:** Allows users to paste email content for security analysis.
- **Activity Monitoring:** Displays email analysis events and security actions.
- **Interactive Dashboard:** Provides an overview of email security statistics.

## 🔍 How It Works

1. Incoming emails are displayed in the dashboard.
2. MailGuard analyses email information.
3. Messages are classified as genuine or spoofed.
4. Suspicious emails are quarantined in the simulation.
5. Users can select individual emails to view their analysis.
6. Users can manually paste email content for additional checking.
7. Activity logs display the actions performed by the system.
